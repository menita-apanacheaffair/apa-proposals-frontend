# A Panache Affair - Proposal Microsite

A luxury, single-page proposal website for A Panache Affair event planning company.

## Overview

This bespoke microsite replaces traditional pitch decks with an interactive, elegant web experience. Built with vanilla HTML, CSS, and JavaScript - no frameworks required.

## Features

### Intro Animation
- Full-screen overlay with gradient background
- Animated ring drawing that transitions into APA wordmark
- Skippable intro for immediate access

### Interactive Elements
- **Package Cards**: Flip to reveal detailed service inclusions
- **Enhancement Cards**: Expand to show complete enhancement details
- **FAQ Accordion**: Smooth expand/collapse functionality
- **Smooth Scroll Navigation**: Seamless scrolling to all sections

### Sections
1. **Welcome/Hero** - Elegant introduction with call-to-action buttons
2. **About** - Company story, founder bio, and credentials
3. **Why APA** - 8 compelling reasons to choose APA
4. **Services** - Overview of planning packages and complimentary offerings
5. **Packages** - Two signature packages (The Whole Nine Yards & Lean on Me)
6. **Enhancements** - 6 bespoke add-on services
7. **Timeline** - 6-stage planning process
8. **FAQs** - 9 comprehensive questions and answers
9. **Contact** - Contact form and company information

## Files

- `styles.css` - Refined luxury styling with soft shadows, rounded corners (18-24px), constrained card heights
- `script.js` - All interactions and animations
- `logo-simple.png` - Simple APA logo for header
- `logo-with-text.png` - Logo with text for intro overlay
- `images/` - Image assets directory
  - `shveta.jpg` - CEO photo (add your photo here - recommended 3:4 aspect ratio, e.g., 600x800px)

## Design Refinements

The current design features luxury editorial aesthetics:
- **Soft Cards**: Large border-radius (18-24px) with multi-level shadows
- **Scrollable Content**: Package/enhancement cards constrained to 80vh with internal scrolling
- **CEO Photo Layout**: Split-column design with elegant rounded frame and border
- **Section Labels**: Editorial numbering (01-08) for magazine-style feel
- **Enhanced Typography**: Responsive clamp() sizing for perfect scaling
- **Refined Micro-interactions**: Subtle hover states and smooth transitions

## Responsive Design

Fully responsive across:
- Desktop (1200px+)
- Tablet (768px - 1199px)
- Mobile (< 768px)

Mobile features include hamburger menu, stacked layouts, and touch-optimized interactions.

## Usage

Simply open `index.html` in any modern web browser. No build process or server required.

For production deployment, upload all three files to any web hosting service.
